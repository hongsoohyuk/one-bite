## 구현 완료 (graduated)

### ✅ 1. 지도 탭 제거 → 등록 플로우의 "만날 위치 선택"으로 전환 (구현됨)

**문제의식 (2026-06-05, 사용자):** 하단 가운데 독립 지도 탭은 실사용 가치가 낮다. 지도는
엔띵 등록 시 "만날 위치"를 찍을 때 쓰는 게 자연스럽다.

**구현 결과:**
- `BottomNav` 는 **홈 / 나** 2탭(+중앙 FAB)으로 축소 — 독립 지도 탭/`/map` 라우트 제거.
- `CreateSplit` 에 `features/map/LocationPicker` 추가: 카카오 장소 검색 + 조절 가능한 핀(좌표) +
  상세 위치 텍스트 필드. `address` 는 `"<장소명> · <상세>"` 로 합쳐 전송, 좌표는 핀 기준(없으면 GPS 폴백).
- 지도 컴포넌트는 `features/map/KakaoMap` 로 유지(등록 화면에서 재사용).

### ✅ 2. 인앱 채팅 (엔띵 성사 후 참여자 간 소통) (구현됨 2026-06-15)

**문제의식 (2026-06-05, 사용자):** 매칭/참여가 되면 만나서 교환하기 위한 채팅이 필요하다.

**구현 결과 (열린 질문 해소):**
- 채팅 단위: **split(반띵) 1개당 1개 그룹챗** (멤버 = 주최자 + 활성 참여자).
- 실시간: **WebSocket + STOMP**(`/ws`, `/topic/chats/{splitId}`) + REST(전송/조회/읽음/안읽음).
  CONNECT 시 JWT 인증, SUBSCRIBE 시 멤버십 인가.
- 푸시 연동: 새 메시지 → 기존 FCM 인프라로 푸시(AFTER_COMMIT 디커플링).
- MVP 범위: 텍스트. (사진/위치 공유는 후속.)
- 명세: `docs/superpowers/specs/2026-06-15-chat-rooms-design.md`.
